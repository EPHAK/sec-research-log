Working notes on systems security — OS internals, Linux kernel source study, CTF/pwn writeups, and eventually vulnerability research.

Raw, dated, not polished. The point is the trail, not the presentation.

- `ctf/` — writeups and re-solves of pwn/CTF challenges.
- `bugbounty/` — notes from reading disclosed HackerOne/Intigriti reports.
